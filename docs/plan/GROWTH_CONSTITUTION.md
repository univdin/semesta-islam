# 1. CORE CONSTITUTIONAL PRINCIPLES

### Rule 1: Paradigm — Syi'ar & Community Distribution Network
SEMESTA ISLAM diposisikan secara mutlak sebagai **Syi'ar & Community Distribution Network**.
Komersialisasi, rujukan, dan reputasi beroperasi di bawah payung Khidmah & Syi'ar untuk memastikan monetisasi tidak merusak keotentikan brand dan nilai keilmuan Islam.

### Rule 2: Three-Engine Growth Model
1. **ENGINE A — ATTENTION ENGINE**: Attention → Trust (Syi'ar, Content, SEO, Social, Diagnostic).
2. **ENGINE B — PARTICIPATION ENGINE**: Trust → Value → Participation → Retention (Learning Journey, Community, Retention Loop, Reputation Signals).
3. **ENGINE C — DISTRIBUTION ENGINE**: Participation → Contribution → Distribution (Syi'ar/Community & Commerce/Revenue).

# 2. ONTOLOGY GUARDRAILS & MANDATORY INVARIANTS

Setiap entitas, struktur data, kontrak API, dan UI **WAJIB** memisahkan secara eksplisit domain berikut:

$$\text{Achievement} \neq \text{XP} \neq \text{Reputation} \neq \text{Credential} \neq \text{Sanad} \neq \text{Verification}$$

> **MANDATORY CONSTITUTIONAL DIRECTIVE**:  
> **XP is a recognition signal, not reputation itself. Reputation is a derived trust/community standing constructed from multiple qualified signals and evidence. XP, Reputation, Credential, Sanad, and Verification MUST remain separate domain concepts, data structures, API contracts, and UI representations.**

### Definisi Domain Formal:
1. **Achievement (Pencapaian Belajar)**: Catatan penyelesaian modul atau aktivitas pembelajaran.
2. **XP (Recognition Score Signal)**: Skor numerik hasil pengukuran atas aktivitas bermakna yang terkualifikasi (*measurement mechanism*).
3. **Reputation (Keaktifan & Kepercayaan Komunitas)**: Evaluasi integritas & kontribusi komunitas yang diturunkan dari konsistensi, peer feedback, verifikasi, dan rekam jejak (*derived trust standing*).
4. **Credential (Kualifikasi Formal)**: Sertifikat formal atau ijazah dari lembaga terakreditasi.
5. **Sanad (Jalur Silsilah Keilmuan)**: Transmisi keilmuan berantai yang terverifikasi.
6. **Verification (Status Audit Lajnah)**: Keputusan formal Dewan Lajnah atas keabsahan dokumen/ijazah pengajar.

> **CONSTITUTIONAL RULE**: XP dan Badge Komunitas **DILARANG** diposisikan, diklaim, atau ditampilkan sebagai Sanad, Ijazah, Credential, atau kualifikasi keilmuan formal dalam bentuk apa pun. Status Sanad **HANYA** dapat diterbitkan oleh Dewan Lajnah.

# 4. GROWTH INTEGRITY & ANTI-GAMING PRINCIPLES

### Integrity Principle:
> **No user shall be rewarded merely for generating activity.**  
> Reward requires: **Intent + Qualification + Uniqueness + Outcome + Integrity**.

### Non-Equivalence Directives:
```text
Traffic      ≠  Value
Click        ≠  Contribution
Share        ≠  Impact
Registration ≠  Qualified User
Booking      ≠  Commission Accrual
XP           ≠  Reputation
Badge        ≠  Credential
```

# 6. COMMERCIAL LIFECYCLE LAWS

Commercial Commission wajib mengikuti tahapan berurutan:
$$\text{Conversion} \rightarrow \text{Commission Accrual} \rightarrow \text{Approval} \rightarrow \text{Settlement} \rightarrow \text{Payout}$$
*Booking Paid* $\neq$ *Commission Paid*. Komisi membutuhkan verifikasi masa tenggang refund & settlement batch formal.
