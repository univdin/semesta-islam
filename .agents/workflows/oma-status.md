# `/oma-status` Workflow

## Goal
Display an active dashboard of OmA personas, active skills, and system context.

## Execution Steps

1. Read `.agents/AGENTS.md` persona configuration.
2. List available workspace skills under `.agents/skills/`.
3. Display current project authority chain (`BRD → BSD → PRD → ERD → OSS → Context`).
