# `/ux-audit` Workflow

## Goal
Audit UI text, microcopy, form validation messages, and marketing copy for human-centric quality and zero AI-slop.

## Execution Steps

1. **Invoke Skills**:
   - Activate `ux-copywriting-master` and `anti-ai-slop`.

2. **Microcopy Review**:
   - Check buttons/CTAs for Verb + Noun format.
   - Verify error messages explain problem + actionable fix.
   - Audit empty states for title + body + CTA structure.

3. **Anti-AI-Slop Sweep**:
   - Flag and replace banned LLM clichés (*delve into*, *seamless*, *game-changer*, *elevate*).

4. **Deliverable**:
   - Provide 3 copy variants (Direct, Warm, Action-Oriented) with rationale.
